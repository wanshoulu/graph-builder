# RSI 对话工作台与加载修复 · 2026-10-30

已在原 `http://localhost:17386/ontomind/knowledge/graph/intent-rsi` 部署。本轮围绕入口超过一分钟、具体任务信息难理解两项问题，重新实现任务列表和对话工作台，并验证原有分析、问题定位、实验、候选与验收功能。

## 用户现在如何使用

列表先回答“哪个任务、当前成绩是否有效、下一步做什么”。显示任务身份、当前有效完全正确率、题目与封存题规模、实验和采纳记录，并提供搜索、状态筛选、刷新、重试、管理和创建。失效的历史 100% 仅作为带明确标记的历史参考。

进入任务默认打开“进化对话”。主区域按一次运行展示已保存的请求、实际分支父子关系、每代计划、诊断证据、测量、保护检查和复盘；选择分支可查看修改与成绩。没有保存计划的历史运行明确显示缺失，不补写模型叙述。可以选择历史运行、进入完整审计或查看执行日志。

右侧分别展示当前任务和所选运行配置、正式资产/引擎联合精度趋势、所选运行各代指标，以及调用、耗时、延迟和已有用量。正式版本、候选成绩、历史成绩和当前有效测量分别标注；没有数据不填零。跨题库、切分等不可比条件处不连线，引擎变化作为引擎/联合变化标记。

底部输入“本轮优化要求”，经已有配置与预检后才能启动。要求实际进入规则提案提示词、模型规划输入或 Agent 上下文，并保存到运行及检查点；恢复运行使用原冻结配置。停止、恢复与候选审阅沿用真实接口。此次验证没有启动收费优化、采纳候选或发布资产。

“全景分析”保留完整趋势、业务意图表现、代际 DAG、题型直方图、资产与引擎组合矩阵和数据明细。“问题定位 → 相关方案 → 方案决策”“跨运行比较 → 精确运行”“验收交付 → 历史版本”的路径仍可使用。窄屏按对话、配置、趋势与其他指标顺序排列。

## 加载为什么慢，改了什么

入口 `/tasks` 为少量列表行调用完整 `productionRuntime.state()`，读取约 31 MB 的 legacy 状态、约 17 MB 的 mobile 状态并重复读取其中一个任务，再计算候选可采纳性、完整详情等。同步读取与计算阻塞服务。浏览器还提前请求创建资源、静态加载详细工作区；直接打开详情又为名称读取全任务列表。原客户端 30 秒超时后没有重试入口。

修复内容：

- 新增轻量 `scoreValidity()`，与详情共用有效性判定，不为列表构建全部候选详情。
- 任务状态异步读取、文件身份缓存、并发请求合并，读取后检查文件是否变化；调用者获得独立对象。损坏任务单独显示读取错误，健康任务仍可展示。
- 列表仅请求轻量任务汇总；创建资源在打开创建表单时读取。详情直接取得本任务状态，分析谱系按页面请求，详细工作区延迟加载。
- 前端合并重复加载，后台页暂停轮询，运行时才提高刷新频率；提供明确错误与重试。请求超时覆盖响应体解析，避免收到响应头后无限等待。

| 测量 | 修复前 | 修复后 |
|---|---:|---:|
| nginx 实际 `/tasks` 请求 | 63.366 秒 | 首次健康请求 6.323 秒、后续一次 0.930 秒 |
| 独立进程读取与汇总剖析 | 19.256 秒 | 2.986 秒 |
| 最终生产复测 `/tasks` | — | 1.437 秒 |
| 新浏览器进入任务列表，直到显示列表 | 超过 90 秒仍无列表；接口在约 30 秒被取消 | 3.494 秒 |
| 新浏览器直接打开 legacy 任务，直到精度趋势就绪 | — | 2.148 秒 |
| 已打开列表后进入 legacy 详情 | — | 1.489 秒 |

以上是同机单次观测，不是分位数或性能承诺。浏览器使用全新上下文；最终浏览器测量时后端已启动并有缓存。前后剖析与真实 HTTP 时序分别保留，不混作同一实验。

## 保留的问题与边界
